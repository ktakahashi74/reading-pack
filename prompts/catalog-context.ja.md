# 人名・用語の本書内説明を作るプロンプト

対象は、すでに採録された人名と用語に限る。`catalog context-plan`が列挙した全対象を、重複なく一件ずつ処理する。

人名の`description`には、その人物が本書で何者として紹介され、どの見解、仕事、引用、評価に結び付けられるかを一文で書く。用語の`description`には、一般辞書の定義ではなく、本書がその語をどの意味または役割で使うかを一文で書く。

原稿にない経歴、一般知識、評価、因果関係を補わない。本文を引用せず、章の代わりとなる詳細を含めず、500字以内で簡潔に言い換える。判断材料が少ない場合も推測せず、「第N章のどの議論に置かれるか」という原稿から確認できる最小限の説明にとどめる。

出力は一つのJSONオブジェクトとし、次の形だけを返す。

```json
{
  "plan_id": "CTX-...",
  "candidates": [
    {
      "record_id": "NAME-...",
      "description": "本書では、……として紹介され、……を論じる際に参照される。",
      "evidence": [
        {
          "snippet": "原稿に正確に存在する8〜500文字の範囲",
          "occurrence": 0,
          "supports_field": "book_context"
        }
      ]
    },
    {
      "record_id": "TERM-...",
      "description": "本書では、……を指す語として用いられる。",
      "evidence": [
        {
          "snippet": "原稿に正確に存在する8〜500文字の範囲",
          "occurrence": 0,
          "supports_field": "book_meaning"
        }
      ]
    }
  ]
}
```

各`evidence`は、対象に指定された章のなかに置く。少なくとも一つの範囲には、人名または用語そのものを含める。複数の範囲が必要なら、同じ項目へ複数付ける。

位置、ハッシュ、レビュー、採否、承認状態は出力しない。ツールが原資料と章を再検査した後、人間または監査記録付きのAIが、意味、帰属、簡潔さを確認する。
