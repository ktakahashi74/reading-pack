# Model-independent prompt library

These prompts help with candidate generation and catalog descriptions. They are optional: the complete workflow can be carried out by hand. No prompt requires a particular provider, model, tool-call format, or API.

Before using an external model, check confidentiality duties, publishing agreements, retention and training terms, and translation rights. Supply only the smallest authorized excerpt. A prompt accepting text is never a reason to paste credentials or an unpublished manuscript in full.

Every model output is a `draft` candidate. An author or editor checks it against the authorized source and decides whether to keep it. Model output cannot establish rights, certainty, falsification conditions, author approval, or publication readiness.
