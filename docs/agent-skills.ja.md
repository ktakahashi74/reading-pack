# Agent Skills配布

読者が使うものは**対話版（Conversational Edition）**であり、その技術的な持ち運び単位が**読解パック（Reading Pack）**である。Agent Skillは、生成済みの読解パックを包む任意の互換コンテナにすぎない。正本にはならず、Markdownの読解パックを置き換えず、新しい承認単位も作らない。

生成するディレクトリは[Agent Skills仕様](https://agentskills.io/specification)に従う。このコンテナには、スクリプト、実行ファイル、hook、plugin、`allowed-tools`宣言を入れない。

## 生成と検査

まず通常の読解パックを生成して検査し、その後で任意のコンテナを作る。

```sh
reading-pack build --project PROJECT --lang all
reading-pack check --project PROJECT --lang all --release
reading-pack agent-skill build --project PROJECT --release
reading-pack agent-skill check --project PROJECT --release
```

`agent-skill build`は、設定された全言語の期待値をメモリ上で再描画し、`dist/`にある通常の読解パックと比較する。一つでも欠けているか古ければ、Agent Skillの出力を変更する前に失敗する。新しいディレクトリとZIPを一時領域へ作り、全体を検査してから以前の配布物と入れ替える。正本データ、テンプレート、通常の読解パック、承認記録には書き込まない。

`agent-skill check`は読み取り専用である。プロジェクトの検証、通常の読解パックの再描画と一致確認を繰り返したうえで、ディレクトリとZIPを新しい期待値とバイト単位で比較する。`--release`を付けると、通常の公開検査と同じ人間の公開判断も確認する。

## 出力

一つのskillに、プロジェクトで設定した全言語を収める。

```text
dist/agent-skill/<slug>/
  SKILL.md
  manifest.json
  references/<output-basename>.<lang>.md
dist/<slug>-agent-skill.zip
```

`references/`内の各ファイルは、対応する通常の読解パックとバイト単位で同一である。`SKILL.md`はホストに対し、質問の言語があればその版を、なければ主言語版を選び、選んだ読解パックを読んで`SYS`に従うよう指示する。ウェブへアクセスできるのは、ホストがその機能を提供し、かつ選択した読解パックが要求した場合だけである。

`manifest.json`にはskill名、読解パックの版、状態、主言語、収録言語、ライセンスを記録する。さらに、`SKILL.md`と収録した各読解パックについて、相対パス、バイト数、SHA-256を記録する。ハッシュは検査時のバイト不一致を見つけるための値であり、電子署名、本人確認、権利処理、公開承認ではない。

ディレクトリに入るのは、記載した制御ファイルと参照ファイルだけである。ZIPは安全なパス順に並べ、時刻と権限を固定し、無圧縮で格納する。同じ入力から繰り返し生成したZIPはバイト単位で同一になる。生成と検査では、シンボリックリンク、通常ファイル以外のもの、path traversal、余分なファイル、スクリプトの混入、過大な入力を拒否する。

## インストールと更新

公開検査が成功した後、対象ホストの説明に従ってインストールする。一般には、生成した`<slug>`ディレクトリをホストのskills用ディレクトリへコピーするか、ZIPを読み込ませる。`SKILL.md`だけを渡してはならない。参照ファイルとmanifestも配布物の一部だからである。

万能なワンクリック・インストールURLはない。Agent Skillsが定めるのはディレクトリ形式であり、検索、アップロード、配置先、権限、更新方法はホストごとに異なる。

更新時は次の順に進める。

1. 通常のレビュー工程で読解パックの正本を更新する。
2. 通常の`build`と`check`を実行する。
3. Agent Skillを再生成して検査する。
4. 対象ホストの手順でインストール済みのskillを入れ替える。

インストール先の参照ファイルを直接編集して更新してはならない。その変更は正本にならず、持続せず、持ち帰って`agent-skill check`を実行すれば不一致になる。

## 汎用ホストでは保証されないこと

このコンテナは、確認済みの読解パックのバイト列を保ち、一般的な利用指示を添える。汎用のAgent Skills対応ホストが、公開条件の強制、鮮度の再検査、監査記録の保存、すべての`SYS`規則の遵守、安全なウェブ接続、無関係なファイルへのアクセス拒否まで保証するわけではない。ホストの挙動と権限は別に評価する必要がある。

専用の`reading-pack-bot`なら、管理されたアップロード、版管理、検査結果、読者向けUI、製品固有の強制処理を追加できる。この汎用Agent Skill配布はそれらを提供しない。すでにAgent Skillsを読み込めるホストへ持ち運ぶための互換経路である。
